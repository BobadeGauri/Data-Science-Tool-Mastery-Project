# Power BI Dashboard Guide

## Goal
Create a one-page Retail Sales Overview using `data/retail_sales_raw.csv` (or the cleaned output generated by the Python script).

## Import and prepare
1. Open Power BI Desktop → Get Data → Text/CSV → choose the CSV.
2. In Power Query, set `date` to Date and numeric columns to Decimal Number / Whole Number.
3. Replace missing `region` and `channel` values with the most frequent values, or import `outputs/retail_sales_cleaned.csv` after running the Python script.
4. Select Close & Apply.

## Suggested DAX measures
```DAX
Total Revenue = SUMX('retail_sales', 'retail_sales'[units_sold] * 'retail_sales'[unit_price])
Total Cost = SUMX('retail_sales', 'retail_sales'[units_sold] * 'retail_sales'[unit_cost])
Total Profit = [Total Revenue] - [Total Cost]
Profit Margin = DIVIDE([Total Profit], [Total Revenue], 0)
Total Units = SUM('retail_sales'[units_sold])
```

## Visuals
- KPI cards: Total Revenue, Total Profit, Profit Margin, Total Units
- Clustered column chart: Revenue by Category
- Line chart: Revenue by Month
- Bar chart: Revenue by Region
- Donut chart: Revenue by Channel
- Slicers: Date, Region, Category, Channel

## Validation
Compare Power BI totals with `outputs/category_summary.csv` and `outputs/monthly_summary.csv`. The repository includes this implementation guide, not a `.pbix` file; save your completed report from Power BI Desktop as `Retail_Sales_Overview.pbix`.
